# Requirements

## Functional requirements (what the system must DO)
1. The system shall provide a live queue tracking dashboard that displays estimated wait times and real-time position updates for customers in line.
2. The system shall allow customers to search, filter, and select barbers based on specific style expertise, pricing tiers, and real-time availability.
3. The system shall dynamically adjust booking time slots and queue intervals based on historical service durations and current peak-hour traffic patterns.
4. The system shall enable barbers and shop managers to update appointment statuses, manage daily walk-ins, and reassign appointments dynamically.
5. The system shall send automated notifications and reminders to clients regarding their upcoming slot or when their queue position is approaching.

## Non-functional requirements (how the system must PERFORM)
1. The system shall update and sync live queue positions and estimated wait times across client devices within 2 seconds of a status change.
2. The system shall support at least 100 concurrent user sessions per barbershop branch without performance degradation during peak weekend hours.
3. The system shall securely encrypt all user authentication data and client personal information in compliance with data privacy standards.
