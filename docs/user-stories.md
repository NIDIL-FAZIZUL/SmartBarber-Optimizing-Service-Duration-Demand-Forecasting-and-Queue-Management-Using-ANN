# User Stories

Format: As a student, I want to make my final year project, so that i can grade on my csp600 project.

1. As a ..., I want ..., so that ...
2. As a ..., I want ..., so that ...
3. As a ..., I want ..., so that ...

**Acceptance Criteria:**
1. Every user story listed in docs/user-stories.md includes a minimum of two clear, testable acceptance criteria points.
2. The acceptance criteria are written using a structured format (such as bullet points or Given-When-Then conditions) that defines when the user story is successfully completed.
